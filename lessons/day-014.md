# Day 14: TypeScript basics

**Week 2 · Programming foundations: modern JavaScript and TypeScript**

## Goal

Understand **TypeScript basics** well enough to use it in a small app feature and explain your choices.

## Example

Type this example and run it in the appropriate environment. Some snippets assume the surrounding project has already been set up (for example, an Express `app`).

```javascript
const focus = "TypeScript basics";
const practiced = true;
console.log(`${focus}: ${practiced}`);
```

## Line-by-line explanation

1. `const focus = "TypeScript basics";` — Stores today’s concept name in a constant string.
2. `const practiced = true;` — Stores a boolean result representing whether you completed the practice.
3. `console.log(\`${focus}: ${practiced}\`);` — Prints both values using a template string so you can see the result.
