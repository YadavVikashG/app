# Day 2: Conditionals and decision making

**Week 1 · Programming foundations: JavaScript essentials**

## Goal

Use a comparison and an `if...else` statement to make a program choose what to do.

## Example project

The runnable code is in [`examples/day-002/`](../examples/day-002/). Open that folder in a terminal and run `node day-02.js`.

```javascript
const learnerName = "Alex";
const topic = "Conditionals and decision making";
const minutesStudied = 45;
const dailyGoalMinutes = 60;

const metDailyGoal = minutesStudied >= dailyGoalMinutes;

if (metDailyGoal) {
  console.log(`${learnerName} met the ${dailyGoalMinutes}-minute goal for ${topic}.`);
} else {
  const remainingMinutes = dailyGoalMinutes - minutesStudied;
  console.log(
    `${learnerName} still needs ${remainingMinutes} more minutes to reach the ${dailyGoalMinutes}-minute goal for ${topic}.`
  );
}
```

## Line-by-line explanation

1. The first two constants store the learner's name and the topic as strings.
2. `minutesStudied` and `dailyGoalMinutes` store numbers that the program can compare and subtract.
3. `minutesStudied >= dailyGoalMinutes` checks whether the learner studied at least the goal. The result is a boolean: `true` or `false`.
4. `if (metDailyGoal)` runs its block when the comparison is `true`.
5. `else` runs when the comparison is `false`.
6. In the `else` block, subtracting the minutes studied from the goal calculates how many minutes remain.
7. The template strings insert the values into a message, and `console.log` prints it.

## Practice task

1. Change `minutesStudied` to `90` and run the program. It should say that the goal was met.
2. Change it to `60` and run it again. The goal should still be met because `>=` includes equality.
3. Try `0`. Check that the program reports the full 60 minutes remaining.
4. Change the learner's name and topic, then run the program again.
