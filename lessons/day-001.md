# Day 1: Variables and basic values

**Week 1 · Programming foundations: JavaScript essentials**

## Goal

Learn how variables hold values, recognize strings, numbers, and booleans, and print those values.

## Example project

The runnable code is in [`examples/day-001/`](../examples/day-001/). Open that folder in a terminal and run `node day-01.js`.

```javascript
// const creates a variable binding that cannot be reassigned.
const learnerName = "Alex";

// This string value stores the learner's name.
const topic = "Variables and basic values";

// This number value stores how many minutes the learner studied.
const minutesStudied = 90;

// This number value stores the daily study target in minutes.
const dailyGoalMinutes = 60;

// >= compares the numbers and produces a boolean: true or false.
const metDailyGoal = minutesStudied >= dailyGoalMinutes;

// console.log prints a label and the learner's name to the terminal.
console.log("Learner:", learnerName);

// A template string inserts the topic and study time into a sentence.
console.log(`${learnerName} studied ${topic} for ${minutesStudied} minutes.`);

// This template string prints the boolean result of the comparison.
console.log(`Met the ${dailyGoalMinutes}-minute goal: ${metDailyGoal}`);
```

## Line-by-line explanation

1. `const learnerName = "Alex";` declares a variable named `learnerName` and stores a string. A string is text inside quotes. `const` means the variable cannot be reassigned.
2. `const topic = "Variables and basic values";` stores another string describing the lesson.
3. `const minutesStudied = 90;` stores a number. Numbers are not surrounded by quotes.
4. `const dailyGoalMinutes = 60;` stores another number for comparison.
5. `const metDailyGoal = minutesStudied >= dailyGoalMinutes;` uses `>=` (“greater than or equal to”). The comparison evaluates to a boolean: `true` or `false`.
6. `console.log("Learner:", learnerName);` prints the label and the value of `learnerName` in the terminal.
7. `` console.log(`${learnerName} studied ${topic} for ${minutesStudied} minutes.`); `` uses backticks to create a template string. Each `${...}` inserts the value of a variable into the text.
8. `` console.log(`Met the ${dailyGoalMinutes}-minute goal: ${metDailyGoal}`); `` prints the goal and the result of the comparison.

## Practice task

1. Change `learnerName` to your name.
2. Change `minutesStudied` to `45`. Run the program and observe that `metDailyGoal` is `false`.
3. Change `minutesStudied` to `60`. Run it again. The result should be `true` because the comparison includes “equal to.”
4. Add a `const minutesRemaining = dailyGoalMinutes - minutesStudied;` variable and print it. What value do you get when you have already exceeded your goal?
