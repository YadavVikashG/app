## Example

Type this example and run it in the appropriate environment. Some snippets assume the surrounding project has already been set up (for example, an Express `app`).

```jsx
function LessonExample() {
  const title = "API calls";
  return <button onClick={() => console.log(title)}>{title}</button>;
}
```

## Line-by-line explanation

1. `function LessonExample() {` — Declares a reusable React component named LessonExample.
2. `  const title = "API calls";` — Stores the displayed title in component-local data.
3. `  return <button onClick={() => console.log(title)}>{title}</button>;` — Returns a button; clicking it logs the title, and the braces insert JavaScript values into JSX.
4. `}` — Closes the component function.
