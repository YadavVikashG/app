## Example

Type this example and run it in the appropriate environment. Some snippets assume the surrounding project has already been set up (for example, an Express `app`).

```tsx
type Lesson = { title: string; done: boolean };
const lesson: Lesson = { title: "Responsive layouts", done: false };
console.log(lesson.title, lesson.done);
```

## Line-by-line explanation

1. `type Lesson = { title: string; done: boolean };` — Defines the required shape of a Lesson object: a string title and a boolean done value.
2. `const lesson: Lesson = { title: "Responsive layouts", done: false };` — Creates a value that follows that type; change done to true after completing the exercise.
3. `console.log(lesson.title, lesson.done);` — Prints the two properties so you can inspect the typed data.
