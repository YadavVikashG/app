# Day 3: Booleans and comparisons

**Week 1 · Programming foundations: JavaScript essentials**

## Goal

Use boolean values and comparison operators to decide whether a shopping app should let a customer buy an item.

## Example

The runnable code is in [`examples/day-003/`](../examples/day-003/). Open that folder in a terminal and run `node day-03.js`.

```javascript
const itemPrice = 24;
const budget = 30;
const quantityInStock = 4;

const isWithinBudget = itemPrice <= budget;
const isInStock = quantityInStock > 0;
const canPurchase = isWithinBudget && isInStock;

console.log(`Within budget: ${isWithinBudget}`);
console.log(`In stock: ${isInStock}`);
console.log(`Can purchase: ${canPurchase}`);
```

## Line-by-line explanation

1. `const itemPrice = 24;` — Stores the item's price as a number.
2. `const budget = 30;` — Stores the customer's maximum budget.
3. `const quantityInStock = 4;` — Stores how many items are available.
4. `const isWithinBudget = itemPrice <= budget;` — `<=` compares the price to the budget and produces a boolean (`true` or `false`).
5. `const isInStock = quantityInStock > 0;` — `>` checks that at least one item is available, producing another boolean.
6. `const canPurchase = isWithinBudget && isInStock;` — `&&` means both conditions must be true for the customer to purchase the item.
7. The three `console.log` lines print each boolean so you can inspect the individual checks and the final decision.

`=` assigns a value, while comparison operators such as `<=`, `>`, and `===` test values and produce a boolean. `&&` requires both conditions to be true; `||` requires at least one to be true; `!` reverses a boolean.

## Practice

1. Change the budget to `20`. The item should no longer be within budget, and `canPurchase` should be `false`.
2. Set `quantityInStock` to `0`. The item should be out of stock, and `canPurchase` should be `false` even if it is within budget.
3. Set the budget to `24`. Check that the item is within budget when the price equals the budget.
4. Add a boolean called `isMember` and use `||` to represent a rule where either membership or an in-budget price qualifies for a discount.
