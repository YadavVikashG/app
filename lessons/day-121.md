# Day 121: App identity

**Week 18 · Deployment: Android release basics**

## Goal

Understand **App identity** well enough to use it in a small app feature and explain your choices.

## Example

Type this example and run it in the appropriate environment. Some snippets assume the surrounding project has already been set up (for example, an Express `app`).

```bash
printf "Today: %s\n" "App identity"
git status --short
```

## Line-by-line explanation

1. `printf "Today: %s\n" "App identity"` — Prints the day’s focus in the terminal.
2. `git status --short` — Shows changed files so you can review your work before committing.
