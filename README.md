# Complete App Developer Roadmap

A 24-week, 168-day study course for building professional mobile apps with React Native, TypeScript, and Expo.

> Plan for about 3–4 focused hours per day. The timeline is a learning target, not a job guarantee. Adjust the pace to your experience.

## How to use the lessons

1. Read the day’s goal and example; type the example yourself rather than copy/pasting it.
2. Follow the line-by-line explanation and run the code in the appropriate project or environment.
3. Complete the practice task, then make one change of your own.
4. Commit your work to Git and write down one question or thing you learned.
5. Mark the day complete only when you can explain the example and modify it independently.

Each lesson has a goal, a small example with a line-by-line explanation, a task, and a completion check. Runnable day-by-day code examples live in [`examples/`](./examples/); each day has its own folder. Day 1 is the completed example of the format: [Day 1 code](./examples/day-001/day-01.js) and [Day 1 lesson](./lessons/day-001.md).
