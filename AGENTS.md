# Instructions for daily lesson work

When creating or updating a day's lesson:

- Keep runnable code inside `examples/day-NNN/`, using the matching day number (for example, `examples/day-002/day-02.js`).
- Never put daily example files at the workspace root.
- Update the matching `lessons/day-NNN.md` so its example, explanation, practice, and run command agree with the code.
- Follow the established lesson and example format; check the previous day's files for the pattern.
- Run the example from its documented location and verify any important cases before finishing.
