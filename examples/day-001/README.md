# Day 1 example: Variables and basic values

This folder contains a small JavaScript program that tracks a learner's name,
today's topic, study time, and whether the daily study goal was met.

## Run it

From this folder, run:

```sh
node day-01.js
```

Expected output:

```text
Learner: Alex
Alex studied Variables and basic values for 90 minutes.
Met the 60-minute goal: true
```

Every code line is commented in [day-01.js](./day-01.js). The linked lesson
explains each line in more detail and gives you a practice task:
[Day 1 lesson](../../lessons/day-001.md).
